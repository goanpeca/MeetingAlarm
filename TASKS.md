# Tasks

The lightweight running board for this solo project — "what am I doing right now." It does
**not** replace the real trackers; it points at them:

- **Formal plans** (intent → spec → build) live in [`docs/exec-plans/`](docs/exec-plans/).
- **Known issues / deferred work** live in [`docs/exec-plans/tech-debt-tracker.md`](docs/exec-plans/tech-debt-tracker.md).
- **Bugs & feature requests** live in GitHub Issues (milestones group a release's work).

Keep this short: a line per task, newest intent at top. Move finished lines to **Done** (or
delete once released). A task big enough to need design gets an exec-plan and is linked here.
