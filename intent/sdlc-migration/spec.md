# Spec — Migrate to the AI-native SDLC playbook (solo)

**Status:** current · **Intent:** [intent.md](intent.md) · **Plan:** [plan.md](plan.md)

## Requirements

- **R1 — Layout.** Per-change artifacts live in `intent/<slug>/{intent,spec,plan}.md`, indexed with
  spec verification status in [`intent/README.md`](../README.md). No `docs/design-docs`,
  `docs/exec-plans`, or `docs/product-specs` remain.
- **R2 — Repo-wide refs.** Cross-cutting docs (`core-beliefs`, `conventions`, `tech-debt-tracker`,
  `QUALITY_SCORE`, `generated/repo-map`) stay in `docs/`; `ARCHITECTURE.md` stays at root.
- **R3 — Review tiers.** [`REVIEW.md`](../../REVIEW.md) picks Quick / Standard / Deep from the
  change; listed sensitive paths are always Deep.
- **R4 — Evidence & honesty.** Findings cite file+line; `Important` / `Nit` / `Pre-existing`
  severities; summaries start with a count and say plainly when nothing needs fixing.
- **R5 — Blocking.** Open Important/Security findings block self-merge until fixed or resolved
  with a reason.
- **R6 — Convergence.** ≤ 3 rounds; then re-review only the new diff; flag bug classes; no repeats.
- **R7 — PR template** asks for Testing, Risk & how to revert, and a changeset.
- **R8 — Changesets.** `CHANGELOG.md` is generated by Changie from `.changes/`; `make changeset`,
  `make changelog`, and `make release` (`changie batch` + `merge`). No release has been cut, so
  all entries sit under `[Unreleased]`.
- **R9 — Gates.** `make ci` green; every relative link resolves (`check-links`).

## Constraint coverage

| Constraint | Covered by |
|---|---|
| Solo — no extra human approvals | R5 (self-merge rule), Gate posture in `AGENTS.md` |
| Keep mechanical harness gates | R9 |
| No behavior change | docs/tooling only; no `Sources/` edits |

## Areas of concern

- **Link churn.** Moving three doc trees rewrites many relative links; `check-links` (R9) is the
  backstop.
- **Changelog fidelity.** Migrated entries are unwrapped to one bullet per line; content preserved.
